The take away message here: When you apply an operator to two different data types, the output might not be obvious! Some operations will work (though it’s not always clear what the final data type will be), while others will raise an error. If it is successful, then the one of the types will be converted to the other. This is called implicit type casting. You can read more about this here.

But if you cannot be bothered/not interested, you should still always check what happens when you combine two data types. Or better yet, you can type cast to make explicit what you’re trying to do!

3 Operations on Lists

We can index lists.

my_lst = [17, 22, 'a', 'r', True]
my_lst[2]
'a'
my_lst[0]
17
my_lst[-1]
True

We can slice lists.

my_lst[:2]
[17, 22]
my_lst[1:3]
[22, 'a']

We can specify the steps

my_lst[::2]
[17, 'a', True]

We can reverse lists

my_lst[::-1]
[True, 'r', 'a', 22, 17]

We can reverse and specify the number of steps

my_lst[::-2]
[True, 'a', 17]

4 Functions

Recall functions:

def frequency(corpus, word):
    """
    Calculates the relative frequency of a word within a corpus. 

    :param corpus: An NLTK Text containing a corpus
    :param word: A word to search for in the corpus

    :return: The proportion of words in corpus that match word
    """
    return corpus.count(word) / len(corpus)

Possible Solutions:

If there are no duplicates, we can use set() to check if the two words are anagrams of each other.

def is_anagram(first_word: str, second_word: str) -> bool:
    """
    Check whether two strings are anagrams of each other. 
    An anagram is formed by rearranging the letters of one word to produce another.
    """
    return set(first_word) == set(second_word)

If there are duplicates, we can use sorted() to check if the two words are anagrams of each other.

def is_anagram(first_word: str, second_word: str) -> bool:
    """
    Check whether two strings are anagrams of each other. 
    An anagram is formed by rearranging the letters of one word to produce another.
    """
    first_word = list(first_word)
    second_word = list(second_word)
    if sorted(first_word) == sorted(second_word):
        return True
    else:
        return False

If you want to be concise, you can also write the above code as:

def is_anagram(first_word: str, second_word: str) -> bool:
    """
    Check whether two strings are anagrams of each other. 
    An anagram is formed by rearranging the letters of one word to produce another.
    """
    return sorted(list(first_word)) == sorted(list(second_word))
is_anagram('listen', 'silent')
True
is_anagram('listen', 'listened')
False

  1. Based on the code provided below, write a function that returns True when x is a palindrome. Example input and expected output is provided below.

Solution:

def is_palindrone(word: str) -> bool:
    """
    Check whether a word is a palindrone
    A palindrome is a word that is spelt the same backwards and forward 
    """
    return word == word[::-1]
is_palindrone('racecar')
True
is_palindrone('hello')
False
