2 UTF8/Latin1 Encoding: Warm Up

Unicode is a universal mapping from characters to numbers called code points. For example, the unicode codepoint of a is 97. You can use the Python function ord to get a character’s unicode codepoint.

ord("a")
97
ord("🐱")
128049

UTF-8 and Latin-1 are two ways to encode these code points as bytes in a file. For basic English characters they produce the same bytes, but for anything else they differ.

word = "schön"

utf8_bytes = word.encode("utf-8")
latin1_bytes = word.encode("latin-1")

print(type(latin1_bytes))

print(f"{word} in UTF-8 encoding is {utf8_bytes}. It is {len(utf8_bytes)} bytes long.")

print(f"{word} in latin1 encoding is {latin1_bytes}. It is {len(latin1_bytes)} bytes long.")
<class 'bytes'>
schön in UTF-8 encoding is b'sch\xc3\xb6n'. It is 6 bytes long.
schön in latin1 encoding is b'sch\xf6n'. It is 5 bytes long.

When Python prints a bytes object, any byte with a value from 0 to 127 (the ASCII range) is shown as its ASCII character, like “s”, “c”, “h”, and “n”. Any byte above 127 is shown as \x followed by its value in hexadecimal, like \xc3. Each \x.. is a single byte.

Why are the number of bytes in UTF-8 encoding longer than in Latin1 encoding?

Let’s see what happens when we try to decode in a different encoding scheme.

utf8_bytes.decode("latin1")
'schÃ¶n'
latin1_bytes.decode('utf-8')
---------------------------------------------------------------------------
UnicodeDecodeError                        Traceback (most recent call last)
Cell In[5], line 1
----> 1 latin1_bytes.decode('utf-8')

UnicodeDecodeError: 'utf-8' codec can't decode byte 0xf6 in position 3: invalid start byte

Let’s try to manually decode Latin1 from UTF-8 encoding.

utf8_character = "ö".encode("utf-8")

utf8_character
b'\xc3\xb6'

Now, use this Unicode online converter to look up what these decimal representations correspond to. Do they look familiar?

You may be wondering how UTF-8 is able to encode one “character” using more than one byte. The answer to this question is part of 1a in HW2, though here is a hint to get you started. Compare the two outputs below. Can you find the Unicode bits hiding inside the UTF-8 bytes?

# UTF-8 encoding of ö in binary
" ".join(format(x, "08b") for x in utf8_character)
'11000011 10110110'
# Unicode code point of ö in binary
format(ord("ö"), "08b")
'11110110'
